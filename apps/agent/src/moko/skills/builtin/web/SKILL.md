---
name: web
description: When and how to use the web — search and fetch — to ground answers.
---
You can reach the open web. Use it rather than guessing:

- `web_search(query)` — find current or factual information you don't hold (a
  fact about the world, a definition, news, "what is X"). It returns top result
  titles and URLs.
- `web_fetch(url)` — read the text of a specific page, including one the
  companion shares with you.

Trust your own knowledge when you're confident; reach for the web when you're
*not*. If you're unsure of a world fact you need to answer — you don't really
know it, or it could be out of date or time-sensitive (recent events, prices,
who currently holds a role) — look it up **then, for that answer**, rather than
guessing. Do it in the moment, for the question in front of you; don't wander
off cataloguing things nobody asked about.

Use the web for *world* facts, never for things only the companion knows about
their own life — for those, ask them or recall from memory. Cite what you found
plainly when it matters. If a fetch or search fails, say so simply rather than
inventing an answer.
